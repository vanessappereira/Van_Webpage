# Drum Kit Player

🔙 [Voltar ao README principal do Portfólio](../../README.md)

## Descrição

O **Drum Kit Player** é uma aplicação web interativa que permite ao utilizador tocar diferentes sons de bateria através do teclado ou de cliques nos botões apresentados no ecrã.

## Estrutura do Projeto / Organização do Código

A aplicação segue uma organização clara e modular, facilitando a leitura e manutenção do código.

```text
drum/
├── images/
│   └── *.png                   # Imagens dos instrumentos
├── sounds/
│   └── *.mp3                   # Sons da bateria
├── css/
│   └── drumStyles.css          # Estilos visuais
├── js/
│   └── drumKit.js              # Lógica do Drum Kit
└── index.html                  # Estrutura principal da página
```

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Audio API)

## Funcionalidades

- Reprodução de sons por clique ou tecla
- Associação entre teclas e instrumentos
- Feedback visual ao pressionar botões
- Experiência interativa em tempo real

## Conclusão

Este projeto demonstra a integração entre eventos de teclado, reprodução de áudio e animações, sendo especialmente útil para compreender interação em aplicações web.
