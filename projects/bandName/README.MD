# Band Name Generator

🔙 [Voltar ao README principal do Portfólio](../../README.md)

## Descrição

O **Band Name Generator** é uma aplicação web que gera nomes de bandas de forma aleatória a partir da combinação de adjetivos e substantivos armazenados num ficheiro JSON.

## Estrutura do Projeto / Organização do Código

O projeto segue uma organização modular, assegurando a separação entre estrutura, estilos e comportamento, de acordo com boas práticas de desenvolvimento web.

```text
bandName/
├── bandName.json           # Ficheiro de dados com adjetivos e substantivos
├── css/
│   └── bandStyles.css      # Estilos específicos da aplicação
├── js/
│   └── bandName.js         # Lógica de geração do nome da banda
└── index.html              # Estrutura principal da página

```

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (ES6)  
- Fetch API  
- JSON  

## Funcionalidades

- Geração aleatória de nomes de bandas
- Leitura dinâmica de dados a partir de ficheiro JSON
- Manipulação do DOM para apresentação do resultado
- Interface simples e responsiva

## Conclusão

Este projeto permite consolidar conhecimentos de JavaScript relacionados com manipulação de dados, interação com o utilizador e consumo de recursos externos, sendo adequado para fins académicos e portfólio.
