# Taco Town

🔙 [Voltar ao README principal do Portfólio](../../README.md)

## Descrição

O **Taco Town** é uma aplicação web interativa que apresenta receitas de tacos com base na escolha do utilizador, utilizando dados armazenados num ficheiro JSON.

## Estrutura do Projeto / Organização do Código

O projeto está organizado de forma a promover reutilização e clareza do código.

```text
taco/
├── images/
│   └── *.png                   # Imagens dos ingredientes
├── css/
│   └── tacoStyles.css          # Estilos da aplicação
├── js/
│   └── tacoRecipes.js          # Lógica de carregamento das receitas
├── recipe.json                 # Dados das receitas
└── index.html                  # Estrutura principal
```

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (ES6)  
- Fetch API  
- JSON  

## Funcionalidades

- Seleção interativa de ingrediente principal
- Carregamento dinâmico de dados via JSON
- Apresentação estruturada das receitas
- Interface simples e intuitiva

## Conclusão

Este projeto reforça o uso da Fetch API e a manipulação de dados estruturados, sendo particularmente relevante para aplicações web dinâmicas baseadas em dados externos.
