# Dice Roller

🔙 [Voltar ao README principal do Portfólio](../../README.md)

## Descrição

O **Dice Roller** é uma aplicação web simples que simula o lançamento de dois dados, apresentando visualmente os resultados e determinando automaticamente o vencedor entre dois jogadores.

## Estrutura do Projeto / Organização do Código

O projeto está organizado de forma modular, separando claramente a estrutura HTML, os estilos CSS, os scripts JavaScript e os recursos visuais.

```text
dice/
├── images/
│   └── dice1.png … dice6.png   # Imagens representativas dos dados
├── css/
│   └── diceStyles.css          # Estilos específicos da aplicação
├── js/
│   └── dice.js                 # Lógica JavaScript do jogo
└── index.html                  # Estrutura principal da página

```

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (ES6)  

## Funcionalidades

- Geração aleatória de valores entre 1 e 6
- Atualização dinâmica das imagens dos dados
- Comparação automática dos resultados
- Indicação visual do vencedor ou empate

## Conclusão

Este projeto permite consolidar conceitos fundamentais de JavaScript, nomeadamente geração de números aleatórios, manipulação do DOM e interação com eventos do utilizador.
