# Aldeias Históricas de Portugal

🔙 [Voltar ao README principal do Portfólio](../../README.md)

## Descrição do Projeto

Este projeto académico consistiu no desenvolvimento de um website estático dedicado às Aldeias Históricas de Portugal, nomeadamente **Almeida, Castelo Rodrigo, Linhares da Beira, Marialva e Monsanto**.

O principal objetivo é consolidar e aplicar os conhecimentos adquiridos em **UFCD 5414 Programação Web Cliente**, através da criação de uma aplicação organizada, funcional e visualmente coerente.

---

## Objetivos

- Aplicar HTML5 para estruturação semântica
- Utilizar CSS3 para layout, responsividade e componentes reutilizáveis
- Implementar JavaScript modular para funcionalidades interativas
- Integrar uma API externa (IPMA) para obtenção de dados reais
- Garantir uma organização clara de ficheiros e pastas

---

## Funcionalidades Implementadas

- Navegação entre páginas e aldeias
- Slideshow manual e automático de imagens
- Conteúdo organizado por secções (Sobre, História, O que ver, Galeria)
- Previsão meteorológica por distrito
- Integração de mapas através do Google Maps
- Estrutura compatível com GitHub Pages

---

## Organização do Código

O projeto encontra-se organizado por responsabilidades:

- `/css` – estilos base, componentes e páginas específicas
- `/js` – lógica dividida por funcionalidades (slideshow, meteorologia, controlo de secções)
- `/pages` – páginas individuais de cada aldeia
- `/images` – recursos visuais e ícones meteorológicos

Esta abordagem facilita a manutenção, reutilização de código e escalabilidade do projeto.

---

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (ES Modules)  
- API IPMA

## Conclusão

O desenvolvimento deste projeto permitiu consolidar conceitos fundamentais de desenvolvimento web, nomeadamente a separação de responsabilidades, consumo de APIs e criação de interfaces interativas sem recurso a frameworks externas.
