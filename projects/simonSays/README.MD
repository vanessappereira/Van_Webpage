# Simon Says

🔙 [Voltar ao README principal do Portfólio](../../README.md)

## Descrição

O **Simon Says** é um jogo de memória baseado na repetição de sequências de cores geradas automaticamente pela aplicação.

## Estrutura do Projeto / Organização do Código

A estrutura do projeto garante separação entre lógica do jogo, estilos e recursos sonoros.

```text
simonSays/
├── sounds/
│   └── *.mp3                   # Sons das cores
├── css/
│   └── simonStyles.css         # Estilos do jogo
├── js/
│   └── simonSaysGame.js        # Lógica principal do jogo
└── index.html                  # Estrutura da aplicação
```

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Audio API)

## Funcionalidades

- Geração automática de sequências
- Progressão por níveis
- Interação por clique
- Feedback visual e sonoro
- Reinício automático após erro

## Conclusão

O Simon Says é um excelente exercício para praticar lógica sequencial, gestão de estado e controlo de fluxo em JavaScript.
