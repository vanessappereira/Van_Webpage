# Oddbods Personality Quiz

🔙 [Voltar ao README principal do Portfólio](../../README.md)

## Descrição

O **Oddbods Personality Quiz** é uma aplicação web interativa que permite ao utilizador descobrir qual personagem Oddbods mais se aproxima da sua personalidade.
O quiz apresenta 15 perguntas dinâmicas e, com base nas respostas, calcula automaticamente o personagem mais compatível.

## Estrutura do Projeto / Organização do Código

O projeto segue uma estrutura modular e organizada, facilitando manutenção, expansão e leitura do código.

```text
quiz/
├── css/
│   └── main.css                # Estilos visuais do quiz
├── data/
│   ├── questions.js            # Perguntas e respostas do quiz
│   └── results.js              # Dados das personagens Oddbods
├── images/
│   └── *.png                   # Imagens das personagens Oddbods
├── js/
│   └── quiz.js                 # Lógica do quiz (pontuação, fluxo, UI)
└── index.html                  # Estrutura principal da página
```

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES Modules)
- Manipulação do DOM
- Estrutura de dados modular (JS/JSON)

## Funcionalidades

- 15 perguntas com respostas dinâmicas
- 11 personagens Oddbods possíveis como resultado
- Sistema de pontuação baseado nas escolhas do utilizador
- Interface simples, intuitiva e responsiva
- Apresentação final com imagem, nome e descrição da personagem
- Possibilidade de reiniciar o quiz

## Conclusão

Este projeto demonstra a integração entre dados externos, manipulação do DOM e lógica de pontuação, criando uma experiência interativa divertida e envolvente.
É especialmente útil para explorar modularização em JavaScript e design de interfaces dinâmicas.
