# Portfólio de Projetos Web

## Descrição

Este repositório reúne um conjunto de projetos web desenvolvidos no âmbito académico, com o objetivo de consolidar conhecimentos fundamentais de **HTML**, **CSS** e **JavaScript**, bem como boas práticas de organização, modularização e separação de responsabilidades no desenvolvimento front-end.

Os projetos variam entre aplicações interativas simples e aplicações com consumo de dados externos, permitindo demonstrar competências progressivas na manipulação do DOM, lógica de programação e interação com o utilizador.

---

## Estrutura do Projeto

O portfólio está organizado de forma modular, com cada projeto alojado numa subpasta própria dentro da diretoria `projects`.  
Recursos partilhados, como estilos globais, ícones e scripts comuns, encontram-se centralizados na pasta `public`.

```text
/
├── index.html              # Página principal do portfólio
├── projects/               # Projetos individuais
│   ├── aldeias/
│   ├── bandName/
│   ├── dice/
│   ├── drum/
│   ├── simonSays/
│   └── taco/
├── public/                 # Recursos globais reutilizáveis
│   ├── css/
│   ├── icons/
│   ├── images/
│   └── js/
└── README.md               # Documentação principal do portfólio
```

Cada projeto contém o seu próprio ficheiro README.md, descrevendo em detalhe a respetiva funcionalidade e organização interna.
